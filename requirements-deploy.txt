# Deployment-only dependency list for the local demo server
# (scripts/demo_server.py) on a persistent host such as Render.
#
# This is DELIBERATELY a subset of requirements.txt, not a replacement for
# it. requirements.txt is unmodified and remains the source of truth for
# local development, data preparation, and the test suite — it is NOT
# proven safe to strip packages from it wholesale (build_delta_dataset.py
# also uses pyarrow directly for parquet I/O, scripts that hit the Kaggle
# API need kaggle, build scripts use tqdm progress bars, and pytest runs
# the test suite). kaggle/tqdm/pytest are genuinely unused by the demo
# server's runtime code path and stay excluded here.
#
# Traced directly from scripts/demo_server.py's actual import graph
# (demo_server -> src.agent -> src.classifier / src.retrieval /
# src.escalation / src.reply_generator), PLUS one dependency that import
# tracing alone missed: pyarrow (see note below) — nothing here is guessed.
#
# ANTHROPIC_API_KEY / the `anthropic` package are intentionally NOT
# included: the demo runs fully offline/deterministic without them (see
# src/reply_generator.py), and no LLM package is imported anywhere in this
# server's code path.

numpy>=1.26.0
pyarrow>=15.0.0         # NOT imported directly by demo_server's code path, but
                        # required at runtime: pandas 3.x backs its string
                        # columns with pyarrow-backed StringDtype whenever
                        # pyarrow is installed, so unpickling corpus_df inside
                        # retrieval_index.pkl needs pyarrow importable even
                        # though nothing here calls it explicitly. Confirmed
                        # by the ModuleNotFoundError on Render and reproduced
                        # locally in an isolated venv without this line.
scikit-learn>=1.4.0
